# 求められる技術が多い案件ほど単価の上限は高いのか。スキルの数で829件を分けた

スキルの数が1個の案件も5以上の案件も、単価の上限の中央値はすべて80万円で変わらず、むしろ最高額は1〜3個の案件の150万円が5以上の案件の120万円を上回っています。この数字は募集に書かれた単価の上限で、2026年11月20日時点で掲載中・募集中の829件のうち単価の上限がわかる799件を集計したものです。自分のスキルの数に近い行を表で確かめてから、応募する案件や提示する単価を決めてください。

## 対象と前提

:::message
- 2026年11月20日時点で掲載中・募集中の案件 829件。月額の単価の上限がわかるのは 799件
- 値は募集に書かれた「単価の上限」。実際の契約額ではない
- 月10万円未満・月300万円超は入力の誤りとして除外
- すべて1つの掲載元の案件で、勤務地は東京が中心。市場全体の相場ではない
- スキルの数は、掲載元が案件に付けたスキルの語の数（必須と歓迎の区別は無い）
:::

## 自分のスキル数の行で単価の目安を確認する

案件を探すときは、まず自分が持つスキルの数に近い行を確認してください。たとえばスキルが5以上の案件では単価の上限の中央値は**80万円**で、真ん中の半分は**75万円**〜**95万円**に収まっています。応募する案件を選ぶときや単価を交渉するときの目安として、この表の自分の行の数字を基準に考えてみてください。

**自分の条件に当てはめる目安**

1. 表で自分のスキルの数の行を探します（例: 1）
2. 提示された単価の上限が**65万円**より低いなら、その行の真ん中の半分より下です。ほかの案件と比べてから決める目安になります
3. **80万円**（中央値）前後なら真ん中、**85万円**を超えるなら高い側です
4. 件数の少ない行は、数件で中央値が動きます。目安にとどめてください

## この集計で言えないこと

:::message alert
- 実際の契約額（ここにあるのは単価の上限）
- 商流の段数（エンド直か何次請けか）
- 経験年数ごとの違い（案件データに経験年数の項目がない）
- 必須スキルと歓迎スキルの違い（データに区別が無い）
:::
