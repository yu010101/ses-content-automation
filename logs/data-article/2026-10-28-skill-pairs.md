# 一緒に求められることが多いスキルの組み合わせと、その単価の上限（780件）

FreelanceDBに掲載中・募集中の案件780件のうち、月額の単価の上限がわかる759件を対象に、同じ案件に一緒に付いていることが多いスキルの組み合わせを集計しました。組み合わせごとの件数と単価の上限を比べられるように、5件以上ある組み合わせだけを表にまとめています。

![よく一緒に求められる組み合わせ 単価の上限（月額）](https://raw.githubusercontent.com/yu010101/ai-lab-zenn/main/images/data/2026-10-28-skill-pairs.png)

## 対象と前提

- 2026年10月28日時点で掲載中・募集中の案件 780件。月額の単価の上限がわかるのは 759件
- 値は募集に書かれた「単価の上限」。実際の契約額ではない
- 月10万円未満・月300万円超は入力の誤りとして除外
- すべて1つの掲載元の案件で、勤務地は東京が中心。市場全体の相場ではない
- 組み合わせは同じ案件に付いていたスキル2つ。5件以上ある組み合わせだけを載せる

## 集計のしかた

集計値は FreelanceDB の公開API https://freelance.radineer.asia/api/public/market-stats から2026-10-28に取得しました。案件ごとの単価の上限から、中央値と「真ん中の半分」（25〜75パーセンタイル、最も近い順位の値）を出しています。

## 表から読めること

- 件数が最も多い組み合わせはRuby + Ruby on Railsの57件で、単価の上限の中央値は90万円、真ん中の半分は75万円〜100万円です。
- React + TypeScriptは52件で中央値85万円、JavaScript + TypeScriptは26件で中央値82.5万円です。
- AWS + TypeScriptは12件で中央値90万円、Java + PHPは13件で中央値80万円、真ん中の半分は80万円〜95万円です。

## この表の使い方

自分が持っているスキルの組み合わせがこの表にあれば、件数と単価の上限の中央値、真ん中の半分の範囲を案件を探すときの目安として参考にできます。例えばLaravel + PHPの組み合わせは36件、中央値75万円、真ん中の半分は60万円〜80万円なので、この組み合わせで案件を探す際の単価の目安として使えます。表はFreelanceDBという1つの掲載元・東京中心の案件に基づくもので、市場全体の相場を示すものではない点に注意してください。

## この集計で言えないこと

- 実際の契約額（ここにあるのは単価の上限）
- 商流の段数（エンド直か何次請けか）
- 経験年数ごとの違い（案件データに経験年数の項目がない）
